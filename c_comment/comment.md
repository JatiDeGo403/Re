* // (double slash): pada hakekatnya command double slash digunakan saat ingin menjelaskan sebuah baris kode atau memberikan sebuah informasi mengenai baris kode tertentu kepada sebuah tim atau anggota yang terlibat dalam sebuah project, double slash ini hanya bersifat satu baris saja apabila di enter, maka terjadi compile error.

* /**/ (slash bintang): sama seperti double slash tetapi fungsi slash bintang bisa digunakan untuk kalimat panjang yang berisi baris-baris tergantung pengguna mau menggunakan kalimat sebanyak apapun, pastikan selalu didalam */, karena jika teks yang ditulis keluar jalur maka terjadi compile error sama seperti double slash.
