# boolean alias bool

boolean hanya memiliki 2 value yaitu true dengan nilai kesepakatan 1 dan false yang mempunyai nilai kesepakatan 0.

boolean biasanya digunakan saat menentukan sebuah kondisi tertentu, sebagai contoh:
a = true;
b = false;
dan logical operatornya &&, jika di runtime maka opsi false akan ditampilkan, karena apapun yang benar saat di && bertemu false hasilnya false, kecuali || alias or
