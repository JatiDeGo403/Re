# penjelasan

* main merupakan function (metode) yang digunakan dalam bahasa pemrograman untuk mengesekusi sebuah program yang sudah dibuat.

* {} (bracket) dalam main terdapat bracket, fungsinya adalah menampung sebuah nilai apapun atau berapapun jumlahnya untuk disimpan atau dieksekusi pada main nantinya.

* ! masih bisa saya lanjutkan nanti

* kegunaan (\n) sama halnya dengan mengetik enter, hal tersebut bisa digunakan sebagai buffer agar teks yang dibuat tanpa menggunakan println! bisa terpisah menjadi 2 baris.

* pastikan gunakan (\n) setelah penggunaan printf atau print biasa, dikarenakan terdapat indikator terminal karena saya menggunakan zsh maka ouput yang dikeluarkan %
