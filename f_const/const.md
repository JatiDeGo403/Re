# constanta penjelasan

* const merupakan sebuah  keyword yang bersifat final dalam artian tidak bisa dirubah dan nilainya tetap akan selalu seperti itu, sebagai contoh PHI = 3.14 dan TIME = 3600 seconds

## perbedaan const dengan mut

* const bersifat final alias tidak bisa dirubah
const harus menggunakan tipe data, jika tidak menggunakan tipe data akan terjadi compile error, const bersifat absolute

* mut merupakan keyword mutable yang artinya bisa dirubah
mut boleh tidak menggunakan tipe data alias opsional (tergantung orangnya)
